# GottaGo

A full-stack application combining an Angular frontend with a backend API.

## Project Structure

- **Frontend**: Angular application
- **Backend**: RESTful API server

## Getting Started

### Prerequisites
- Node.js and npm
- Git

### Installation

1. Clone the repository
```bash
git clone <repo-url>
cd GottaGo
```

2. Install dependencies
```bash
npm install
```

### Running the Application

#### Frontend
```bash
npm run start
```

#### Backend
```bash
npm run server
```

## Development

- Make changes to frontend code in the `src/` directory
- Make changes to backend code in the `backend/` directory
- Commit changes with meaningful messages
